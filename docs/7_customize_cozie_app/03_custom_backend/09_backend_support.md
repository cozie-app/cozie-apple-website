# Support

This page covers backend, API, database, and data retrieval support. For general Cozie AppStore support, see [Cozie Support](/docs/support). For source-code customization and custom app development support, see [App Developer Support](/docs/customize_cozie_app/app_developer_support).

There are several ways to get help for Cozie:
- Open an issue on Github: https://github.com/cozie-app/cozie-apple/issues
    - Bugs in the API
    - Bugs in CoziePy
    - Any kind of technical issue
- Contact us at [cozie.app@gmail.com](mailto:cozie.app@gmail.com?subject=Cozie%20Apple%20Support%20Link)
    - Request an API key
